# Luciana Queiroz - Sommelière

Site institucional desenvolvido com Next.js e otimizado para Vercel.

## 🚀 Tecnologias

- Next.js 14
- React 18
- TypeScript
- CSS Modules

## 📦 Instalação

```bash
npm install
```

## 🏃 Executar em desenvolvimento

```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

## 🏗️ Build para produção

```bash
npm run build
npm start
```

## 🌐 Deploy na Vercel

1. Conecte seu repositório GitHub à Vercel
2. A Vercel detectará automaticamente o Next.js
3. O deploy será feito automaticamente a cada push

Ou use a CLI da Vercel:

```bash
npm i -g vercel
vercel
```
